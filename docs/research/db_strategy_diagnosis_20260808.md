## 구현 우선순위

1. 종목별 정규장 terminal bar·예상 커버리지·장 마감 후 재수집을 기록하는 세션
   완결성 계층을 추가하고 통과 전 `finalized=1`을 거부한다.
2. 2026-07-14 등 불완전 날짜를 재수집·격리한 뒤 paper 체인을 첫날부터
   재구축한다. 중간 equity만 수정하지 않는다.
3. 전략·benchmark 계산 전에 stock code 기준 유니버스를 단일화하고 섹터명은
   별도 정규화한다.
4. 불변 underlying `trade_id`와 `strategy_axis`를 분리하고 시각, 섹터, 룰,
   거절사유, 전략버전, 파라미터 해시, 실현/MTM을 보존한다.
5. `equity[t] = equity[t-1] * (1 + day_ret[t])`와 일별 거래수=원장 거래수
   불변식을 확정 게이트로 강제한다.
6. GM과 v4r 공유현금 계좌축 및 동일 시간·동일 gross exposure benchmark를 만든다.
7. 0.5/0.8/1.0% 비용, 스프레드·유동성·갭·부분체결·상하한가 스트레스를 의무화한다.
8. P0 수정 후 정의를 동결하고 최소 60거래일·40개 실제 배분 거래와 8~12주
   forward로 승격을 판단한다.
