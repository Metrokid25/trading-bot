## 독립 감사와 판정

독립 리뷰어가 원본 수치, 최신 섹터 dedup, 비용 1회 차감, 공유현금 선택 순서와
60분 근사를 재현했다. 기존 진단의 `-0.17%·35선택`과 최신 원본
`-0.09%·34선택` 차이는 코리아써키트의 중복 섹터를 과거에는 `기판`, 최신 정책은
`반도체`로 선택한 데서 발생했다.

복구본도 독립 재현 수치가 위 표와 일치했다. 원본/복구본 비교에서 7월 14일 외
6,246,343봉은 추가·삭제·값 변경이 모두 0이었고, 7월 14일만 34,668키 추가와
기존 1,227키 교체가 있었다. 7월 15일 선택 종목의 전일종가가 09:51 불완전 봉에서
15:30 종가로 바뀐 것도 확인해 이전 종가 오염이 해소됐다.

전략 채택 판정은 다음 이유로 아직 **NO-GO**다.

1. 10시 제한은 같은 25거래일에서 발견하고 평가한 인샘플이며 실제 선택은 17건뿐이다.
2. `paper_universe_log`는 장 마감 뒤 기록되어 진입 시점 멤버십을 완전히 증명하지
   못하고 canonical pick ID도 보존하지 않는다.
3. MDD는 일말 NAV라 장중 낙폭이 아니며, 3분봉 종가 즉시체결·고정비용 가정이다.
4. 새 P0 게이트는 앞으로 날짜별 독립 NXT 메타데이터를 저장하지만, 기존 과거일의
   exact-day 메타데이터와 전체 분봉이 preflight를 통과해야 운영 paper 체인을
   안전하게 재구축할 수 있다. preflight는 저장된 `paper_universe_log` code-day를
   기준으로 하므로 로그 자체가 통째로 빠진 날짜는 별도 거래일 대조가 필요하다.

따라서 기존 v2는 기준축으로 유지하고 `entry_until=10:00`은 코드 기본값을 바꾸지
않은 별도 shadow 관찰축 후보로만 둔다. 60분 청산과 v2_qv 승격은 기각한다.
